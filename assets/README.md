# Image assets

The app includes original vector crests inspired by the supplied poster colors and symbols, plus a KPL wordmark. To use exact original poster artwork instead, add cropped image files using the names below; PNG/WebP/JPG/JPEG files override the included SVG crests.

## Team logos

Copy each cropped team logo into `team_logos/` using the matching team ID as its filename (PNG, WebP, JPG, or JPEG):

- `varanasi.png`
- `og_power_star.png`
- `race_gurram.png`
- `royal_strikes.png`
- `devara_dragons.png`

## Cricket imagery

The home page includes an original illustrated cricket-night hero image at `cricket/hero.svg` and a Kodihalli Premier League wordmark at `cricket/kpl_brand.svg`. To use supplied artwork instead, add `cricket/hero.jpg` and/or `cricket/kpl_brand.png` (PNG, WebP, JPG, or JPEG); raster images take priority over the included SVG.

Use cropped image files rather than an entire schedule poster if you want crisp logo cards. Keep originals at good resolution and crop tightly around each crest/logo.
